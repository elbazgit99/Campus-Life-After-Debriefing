# CAMPUS LIFE  

A mini-Project Based on A **figma Mockup** UI/UX, Using Static Technologies such us **HTML,CSS**  
With **git** For Distributing Version Controll, and **GitHub** as a Remote Storage.


## Project Purposes:   

is the very first **sprint Increament** to validate during youcode campus 2026 ,  
as a follow up **Agile Scrum** Methodolgie in Real Time Implementation.  

With amount of **three UI Pages**, all Campus 1st classes and Colleagues,  
Take This Project as a Challenge rather Than a Sprint to be Debriefied in,  
Whith **3 Days** as a Dead line To implement all The Technologies,Principles,Skills and Tools Learned During the Spring Planing.

## Technologies And Tools:  

**GitFlow** (GitHub norms and standards)  
**Mockups & UI/UX:** wireframes, layout planning (zoning), interpreting Figma mockups.  
**HTML5:** semantic structure, forms, basic SEO, WAI-ARIA accessibility.  
**CSS3:** cascade, selectors, box model, CSS units and variables.  
**Layout:** Flexbox.  
**Git/GitHub:** init, add, commit, push, repositories, and commit best practices.
